# Agent 工具链目录（与 Godot 工程隔离）

> 本目录存放 **AI Agent 的工具链**：自动化脚本、辅助工具、Agent 专属配置与交接文档。
> **它不是 Godot 工程的一部分**——与工程文件物理隔离、互不依赖，工程不引用本目录内任何内容。

## 用途

- 自动化脚本 / 辅助工具（测试跑批、资源检查、构建辅助等）；
- Agent 专属配置与数据；
- 交接文档：Agent 交还控制权时记录进度与未提交内容（见下方「交接」）。

## 隔离约定（必须遵守）

1. 本目录内容**禁止被 Godot 工程引用**：工程代码不得 `load()` / `preload()` / 访问 `res://agent/` 下任何文件；场景、脚本、Autoload、插件均不得依赖本目录。
2. 本目录**禁止混入工程文件**：`scenes/` / `scripts/` / `modules/` / `glue/` / `autoload/` / `addons/` / `tests/` 等工程目录不放 Agent 专属内容。
3. **删除 / 停用本目录后，工程必须仍可正常打开、加载、运行**（`godot --path . --editor` 与 `godot --path .` 无报错）。
4. 中间产物（缓存、临时文件、生成数据）只放本目录内，且遵守 `.gitignore`（不提交），不污染工程目录。
5. 不提交密钥 / token / 密码 / 本机绝对路径 / 个人账号信息（见 DEVELOPMENT.md §2）。

## 交接（人类随时可人工接管）

- 人类可随时直接在 Godot 编辑器中接管工程，Agent 不持有任何独占锁、不留「必须由 Agent 维护」的文件。
- Agent 交还控制权时（完成任务 / 被中断 / 人类接管），在此登记：当前进度、未提交内容（git status）、下一步建议。
- Agent 重新介入前，先读取工程现状（`git log` / `git status` / 工程文件 / 本目录交接文档）再继续。

> 规范出处：AGENTS.md §4.5、DEVELOPMENT.md §1 / §5 / §8。
